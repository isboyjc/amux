**OAuth** 模块用于连接第三方 OAuth 账号并构建 API Key 池，实现多账号间的负载均衡和更高配额。

![OAuth](/images/2api_zh.png)

## 支持的提供商

| 提供商 | 描述 |
| --- | --- |
| **Antigravity** | 基于 OAuth 的 API 访问 |
| **Codex** | 基于 OAuth 的 API 访问 |

## 添加账号

1. 进入 **OAuth** 页面
2. 选择提供商标签页（Antigravity 或 Codex）
3. 点击 **Add Account**
4. 弹出授权对话框 — 在弹窗中完成 OAuth 授权流程
5. 授权完成后账号出现在列表中

{/* IMAGE: OAuth 授权对话框 */}

## 密钥池

多个 OAuth 账号可以组成 **Pool Provider** — 一种自动在多个账号间轮询的特殊提供商，用于：

- **负载均衡**：在多个账号间均匀分配请求
- **更高配额**：合并多个账号的配额上限
- **冗余备份**：如果一个账号被限速，其他账号继续工作

### 工作原理

创建 Pool Provider 后，Amux Desktop 在处理请求时自动在已启用的账号间循环。这对客户端完全透明 — 客户端看到的是一个普通的提供商端点。

{/* IMAGE: Pool Provider 包含多个账号 */}

## 管理账号

| 操作 | 描述 |
| --- | --- |
| **启用/禁用 Pool** | 切换账号是否参与轮询池 |
| **刷新 Token** | 手动刷新账号的 OAuth 访问令牌 |
| **更新配额** | 调整账号的使用配额设置 |
| **删除** | 永久移除账号 |

{/* IMAGE: 账号管理操作 */}

## Pool Provider

当你为某个提供商添加第一个 OAuth 账号时，Amux Desktop 可以自动在 Providers 页面创建一个 **Pool Provider** 条目。此 Pool Provider：

- 与普通提供商并列显示
- 可作为桥接代理的出站提供商
- 可启用为直通代理
- 自动在池中所有已启用账号间负载均衡
