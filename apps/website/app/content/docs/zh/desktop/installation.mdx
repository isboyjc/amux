## 系统要求

| 平台 | 要求 |
| --- | --- |
| **macOS** | macOS 10.15 (Catalina) 及以上，Intel 或 Apple Silicon |
| **Windows** | Windows 10 及以上，64 位 |
| **Linux** | Ubuntu 20.04+、Debian 11+、Fedora 36+ 或同等版本 |

## 下载

从 [GitHub Releases](https://github.com/isboyjc/amux/releases) 页面下载最新版本。

| 平台 | 文件 | 架构 | 下载 |
| --- | --- | --- | --- |
| macOS | `amux-desktop-x.x.x.dmg` | Universal (Intel + Apple Silicon) | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Windows | `amux-desktop-x.x.x-setup.exe` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Linux | `amux-desktop-x.x.x.AppImage` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Linux (Debian) | `amux-desktop-x.x.x.deb` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |

## 安装步骤

### macOS

1. 打开下载的 `.dmg` 文件
2. 将 **Amux Desktop** 拖到 **Applications** 文件夹

{/* IMAGE: macOS 安装 - 拖入 Applications */}

#### macOS 安全提示

由于应用未经 Apple 公证，macOS 可能显示**"已损坏"**或**"无法打开"**的错误。以下是三种解决方法：

**方法 1：右键打开**

1. 右键点击（或 Control+点击）应用图标
2. 从菜单中选择**"打开"**
3. 在安全对话框中点击**"打开"**

**方法 2：系统设置放行**

1. 尝试打开应用（会被阻止）
2. 前往 **系统设置 > 隐私与安全性**
3. 向下滚动找到"已阻止 Amux"的提示
4. 点击**"仍要打开"**
5. 在确认对话框中点击**"打开"**

**方法 3：移除隔离属性（终端）**

```bash
xattr -dr com.apple.quarantine /Applications/Amux.app
```

如果应用在下载文件夹中：

```bash
xattr -dr com.apple.quarantine ~/Downloads/Amux.app
```

<Callout type="info">
使用任一方法后，应用将可以正常打开，无需重复操作。
</Callout>

### Windows

1. 运行下载的 `.exe` 安装程序
2. 按安装向导完成安装
3. Amux Desktop 将添加到开始菜单

{/* IMAGE: Windows 安装向导 */}

### Linux

**AppImage：**

```bash
chmod +x amux-desktop-x.x.x.AppImage
./amux-desktop-x.x.x.AppImage
```

**Debian/Ubuntu (.deb)：**

```bash
sudo dpkg -i amux-desktop-x.x.x.deb
```

## 数据目录

Amux Desktop 的配置、数据库和日志存储在以下位置：

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/amux-desktop/` |
| Windows | `%APPDATA%/amux-desktop/` |
| Linux | `~/.config/amux-desktop/` |

该目录包含：

| 文件/文件夹 | 描述 |
| --- | --- |
| `database.sqlite` | 本地数据库（提供商、代理、日志、令牌等） |
| `logs/` | 应用日志文件 |
| `presets/` | 缓存的提供商预设 |

## 从源码构建

如果你需要从源码构建：

```bash
git clone https://github.com/isboyjc/amux.git
cd amux

# 安装依赖
pnpm install

# 开发模式运行
cd apps/desktop
pnpm dev

# 构建分发包
pnpm package
```

平台特定构建：

```bash
pnpm package:mac      # macOS (.dmg)
pnpm package:win      # Windows (.exe)
pnpm package:linux    # Linux (.AppImage, .deb)
```
