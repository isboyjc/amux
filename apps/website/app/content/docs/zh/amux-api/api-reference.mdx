Amux API 平台提供完整的 RESTful API 接口，完全兼容 [OpenAI API](https://platform.openai.com/docs/api-reference) 格式。所有请求均使用 Bearer Token 认证。

## Base URL

```
https://amux.ai
```

## 认证方式

所有 API 请求需要在 `Authorization` 请求头中携带 Bearer Token：

```
Authorization: Bearer your-amux-api-token
```

请在 [https://amux.ai](https://amux.ai) 创建您的 API 令牌。详见[快速开始](/zh/docs/amux-api/quick-start)。

## 对话补全 (Chat Completions)

根据对话历史创建模型响应，支持流式和非流式响应。

```
POST /v1/chat/completions
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型 ID（如 `gpt-5.4`、`grok-3`） |
| `messages` | array | 是 | 对话消息列表 |
| `stream` | boolean | 否 | 启用流式响应，默认 `false` |
| `temperature` | number | 否 | 采样温度（0-2），默认 `1` |
| `top_p` | number | 否 | 核采样参数（0-1），默认 `1` |
| `max_tokens` | integer | 否 | 最大生成 Token 数 |
| `max_completion_tokens` | integer | 否 | 最大补全 Token 数 |
| `n` | integer | 否 | 生成数量，默认 `1` |
| `stop` | string\|array | 否 | 停止序列 |
| `presence_penalty` | number | 否 | 存在惩罚（-2 到 2），默认 `0` |
| `frequency_penalty` | number | 否 | 频率惩罚（-2 到 2），默认 `0` |
| `tools` | array | 否 | 工具列表（函数调用） |
| `tool_choice` | string\|object | 否 | 工具选择策略 |
| `response_format` | object | 否 | 响应格式（如 JSON 模式） |
| `seed` | integer | 否 | 随机种子，用于可复现生成 |
| `reasoning_effort` | string | 否 | 推理强度：`low`、`medium`、`high` |

### 消息对象

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `role` | string | `system`、`user`、`assistant` 或 `tool` |
| `content` | string\|array | 消息内容（文本或多模态） |
| `name` | string | 可选的参与者名称 |
| `tool_calls` | array | 助手的工具调用 |
| `tool_call_id` | string | 响应的工具调用 ID |

### 示例

```bash
curl https://amux.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "你好！"}
    ]
  }'
```

### 响应

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "gpt-5.4",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "你好！有什么可以帮助你的吗？"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 20,
    "completion_tokens": 10,
    "total_tokens": 30
  }
}
```

### 流式响应

设置 `stream: true` 以接收 Server-Sent Events (SSE)：

```bash
curl https://amux.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "gpt-5.4",
    "messages": [{"role": "user", "content": "你好！"}],
    "stream": true
  }'
```

每个 SSE 事件包含一个 `data:` 行，内含 JSON 数据块。流以 `data: [DONE]` 结束。

## 文本补全 (Completions)

根据提示创建文本补全（旧版接口）。

```
POST /v1/completions
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型 ID |
| `prompt` | string\|array | 是 | 文本提示 |
| `max_tokens` | integer | 否 | 最大生成 Token 数 |
| `temperature` | number | 否 | 采样温度 |
| `top_p` | number | 否 | 核采样参数 |
| `n` | integer | 否 | 生成数量 |
| `stream` | boolean | 否 | 启用流式响应 |
| `stop` | string\|array | 否 | 停止序列 |
| `suffix` | string | 否 | 补全后追加的文本 |

### 示例

```bash
curl https://amux.ai/v1/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "gpt-5.4",
    "prompt": "写一首关于编程的俳句："
  }'
```

## 文本嵌入 (Embeddings)

将文本转换为向量嵌入。

```
POST /v1/embeddings
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 嵌入模型 ID（如 `text-embedding-ada-002`） |
| `input` | string\|array | 是 | 要嵌入的文本 |
| `encoding_format` | string | 否 | 编码格式：`float`（默认）或 `base64` |
| `dimensions` | integer | 否 | 输出向量维度 |

### 示例

```bash
curl https://amux.ai/v1/embeddings \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "text-embedding-ada-002",
    "input": "你好世界"
  }'
```

### 响应

```json
{
  "object": "list",
  "data": [
    {
      "object": "embedding",
      "index": 0,
      "embedding": [0.0023064255, -0.009327292, ...]
    }
  ],
  "model": "text-embedding-ada-002",
  "usage": {
    "prompt_tokens": 2,
    "total_tokens": 2
  }
}
```

## 图像生成 (Images)

根据文本提示生成图像。

```
POST /v1/images/generations
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | string | 是 | 图像的文本描述 |
| `model` | string | 否 | 模型（如 `dall-e-3`、`gpt-image-1`） |
| `n` | integer | 否 | 生成数量（1-10） |
| `size` | string | 否 | 图像尺寸（如 `1024x1024`） |
| `quality` | string | 否 | 图像质量 |
| `style` | string | 否 | 图像风格 |
| `response_format` | string | 否 | 返回格式：`url` 或 `b64_json` |

### 示例

```bash
curl https://amux.ai/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "dall-e-3",
    "prompt": "一只可爱的猫咪坐在笔记本电脑上",
    "size": "1024x1024"
  }'
```

## 音频 (Audio)

### 文本转语音

将文本转换为音频。

```
POST /v1/audio/speech
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | TTS 模型（如 `tts-1`、`tts-1-hd`） |
| `input` | string | 是 | 要转换的文本（最多 4096 字符） |
| `voice` | string | 是 | 音色：`alloy`、`echo`、`fable`、`onyx`、`nova`、`shimmer` |
| `response_format` | string | 否 | 格式：`mp3`、`opus`、`aac`、`flac`、`wav`、`pcm`，默认 `mp3` |
| `speed` | number | 否 | 速度（0.25-4.0），默认 `1` |

### 语音转文本

将音频转录为文本。

```
POST /v1/audio/transcriptions
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 音频文件 |
| `model` | string | 是 | 模型（如 `whisper-1`） |
| `language` | string | 否 | 语言代码 |
| `response_format` | string | 否 | 输出格式 |

## 视频生成 (Videos)

根据文本提示或图像生成视频，兼容 OpenAI Sora API 格式。

```
POST /v1/videos
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 否 | 模型 / 风格 ID |
| `prompt` | string | 否 | 文本描述提示词 |
| `image` | string | 否 | 图片输入（URL 或 Base64） |
| `duration` | number | 否 | 视频时长（秒） |
| `width` | integer | 否 | 视频宽度 |
| `height` | integer | 否 | 视频高度 |
| `fps` | integer | 否 | 视频帧率 |
| `seed` | integer | 否 | 随机种子 |
| `n` | integer | 否 | 生成视频数量 |
| `response_format` | string | 否 | 响应格式 |
| `metadata` | object | 否 | 扩展参数（如 `negative_prompt`、`style`、`quality_level`） |

### 示例

```bash
curl https://amux.ai/v1/videos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "sora",
    "prompt": "一只猫在日落时分的海滩上行走",
    "duration": 5,
    "width": 1920,
    "height": 1080
  }'
```

### 响应

```json
{
  "id": "video-xxx",
  "object": "video",
  "model": "sora",
  "status": "completed",
  "progress": 100,
  "created_at": 1234567890,
  "seconds": "5",
  "completed_at": 1234567900,
  "expires_at": 1234654290,
  "size": "1920x1080",
  "metadata": {}
}
```

<Callout type="info">
视频生成为异步任务。初始响应可能返回 `status: "processing"`，请轮询任务状态直到完成。
</Callout>

## 实时语音 (Realtime)

建立 WebSocket 连接用于实时音频对话。

```
GET /v1/realtime
```

连接 URL：`wss://amux.ai/v1/realtime?model=gpt-4o-realtime`

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 否 | 实时会话使用的模型 |

### 认证方式

在 WebSocket 握手时通过 `Authorization` 请求头传递 Bearer Token：

```
Authorization: Bearer your-amux-api-token
```

### 示例

```javascript
const ws = new WebSocket(
  'wss://amux.ai/v1/realtime?model=gpt-4o-realtime',
  { headers: { 'Authorization': 'Bearer your-amux-api-token' } }
);

ws.on('open', () => {
  console.log('已连接到实时会话');
});

ws.on('message', (data) => {
  console.log('收到消息:', JSON.parse(data));
});
```

<Callout type="info">
这是一个 WebSocket 端点，请使用 WebSocket 协议（`wss://`）连接，而非标准 HTTP。
</Callout>

## 文档重排序 (Rerank)

根据查询对文档列表进行相关性重排序。

```
POST /v1/rerank
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 重排序模型（如 `rerank-english-v2.0`） |
| `query` | string | 是 | 查询文本 |
| `documents` | array | 是 | 要重排序的文档列表 |
| `top_n` | integer | 否 | 返回前 N 个结果 |
| `return_documents` | boolean | 否 | 是否在响应中包含文档内容，默认 `false` |

### 示例

```bash
curl https://amux.ai/v1/rerank \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-amux-api-token" \
  -d '{
    "model": "rerank-english-v2.0",
    "query": "什么是机器学习？",
    "documents": [
      "机器学习是人工智能的一个子领域。",
      "今天天气不错。",
      "深度学习使用神经网络。"
    ],
    "top_n": 2
  }'
```

### 响应

```json
{
  "id": "rerank-xxx",
  "results": [
    {
      "index": 0,
      "relevance_score": 0.95
    },
    {
      "index": 2,
      "relevance_score": 0.82
    }
  ],
  "meta": {}
}
```

## 错误处理

所有错误响应遵循以下格式：

```json
{
  "error": {
    "message": "错误描述",
    "type": "error_type",
    "param": "parameter_name",
    "code": "error_code"
  }
}
```

### 常见状态码

| 状态码 | 说明 |
| --- | --- |
| `200` | 请求成功 |
| `400` | 请求错误 — 参数无效 |
| `401` | 未授权 — API 令牌无效或缺失 |
| `429` | 请求过多 — 超出速率限制 |
| `500` | 服务器内部错误 |

## 速率限制

速率限制取决于您的账户等级和令牌配置。如果收到 `429` 响应，请降低请求频率或联系平台支持。

- 所有接口完全兼容 [OpenAI API](https://platform.openai.com/docs/api-reference) 格式
