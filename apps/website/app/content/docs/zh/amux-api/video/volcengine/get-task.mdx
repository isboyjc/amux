通过 [创建视频生成任务](./create-task) 返回的 `id` 查询任务状态。

## 通用说明

| 项 | 值 |
| --- | --- |
| **请求方法** | `GET` |
| **请求路径** | `/api/v3/contents/generations/tasks/{task_id}` |
| **完整 URL** | `https://api.amux.ai/api/v3/contents/generations/tasks/{task_id}` |
| **认证方式** | `Authorization: Bearer <AMUX_API_KEY>` |
| **请求体** | 无 |
| **响应格式** | `application/json` |
| **任务隔离** | 仅能查询自己创建的任务 |

## 路径参数

<TypeTable
  type={{

<TypeTable
  type={{

    duration: { type: 'integer', description: <>时长（秒）</> },
    ratio: { type: 'string', description: <>宽高比，如 <code>16:9</code></> },

> 未就绪 / 不适用的字段会被省略（生成中无 `content` / `usage`；成功时无 `error`）。

## 响应示例

### 生成中

```json
{
  "id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "model": "doubao-seedance-2.0-fast",
  "status": "running",
  "created_at": 1779902412,
  "updated_at": 1779902468
}
```

### 成功

```json
{
  "id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "model": "doubao-seedance-2.0-fast",
  "status": "succeeded",
  "content": { "video_url": "https://r.amux.ai/cv/.../mp4-720p-....mp4" },
  "resolution": "720p",
  "duration": 8,
  "ratio": "16:9",
  "usage": { "completion_tokens": 173700, "total_tokens": 173700 },
  "created_at": 1779902412,
  "updated_at": 1779903017
}
```

### 失败

```json
{
  "id": "task_xxx",
  "model": "doubao-seedance-2.0-fast",
  "status": "failed",
  "error": { "code": "task_failed", "message": "具体失败原因" },
  "created_at": 1779902412,
  "updated_at": 1779902500
}
```

## 状态值

| status | 含义 |
| --- | --- |
| `queued` | 排队中（含已提交 / 未开始） |
| `running` | 生成中 |
| `succeeded` | 成功，`content.video_url` 可用 |
| `failed` | 失败，见 `error` |

## 轮询建议

创建后用返回的 `id` 轮询查询端点，直到 `status` 为 `succeeded` 或 `failed`，建议间隔 3 ~ 5 秒。
