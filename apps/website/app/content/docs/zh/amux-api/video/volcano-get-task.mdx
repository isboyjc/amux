title: 查询任务状态（火山 v3 格式）
description: 火山方舟（Seedance）v3 协议 — 查询视频生成任务状态。返回火山官方 v3 任务结构（网关归一化），含状态、视频地址、用量与错误信息
---

通过 [创建视频生成任务（火山 v3 格式）](./volcano-create-task) 返回的 `id` 查询任务状态。返回**火山官方 v3 任务结构**（经网关归一化）。

## 通用说明

| 项 | 值 |
| --- | --- |
| **请求方法** | `GET` |
| **请求路径** | `/api/v3/contents/generations/tasks/{task_id}` |
| **完整 URL** | `https://api.amux.ai/api/v3/contents/generations/tasks/{task_id}` |
| **认证方式** | `Authorization: Bearer <AMUX_API_KEY>` |
| **请求体** | 无 |
| **响应格式** | `application/json` |
| **任务隔离** | 仅能查询自己创建的任务 |

`{task_id}` 为创建接口返回的 `id`。

## 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 网关任务 ID |
| `model` | string | 模型名 |
| `status` | string | `queued` / `running` / `succeeded` / `failed` |
| `content` | object | 成功时存在，`{ "video_url": "..." }` |
| `content.video_url` | string | 视频地址（经网关脱敏 / 代理改写，不暴露上游直链） |
| `resolution` | string | 分辨率，如 `720p` |
| `duration` | int | 时长（秒） |
| `ratio` | string | 宽高比，如 `16:9` |
| `usage.completion_tokens` | int | 生成 token 数 |
| `usage.total_tokens` | int | 总 token 数 |
| `error` | object | 失败时存在，`{ "code": "...", "message": "..." }` |
| `created_at` | int | 创建时间（Unix 秒） |
| `updated_at` | int | 更新时间（Unix 秒） |

> 未就绪 / 不适用的字段会被省略（生成中无 `content` / `usage`；成功时无 `error`）。

## 响应示例

### 生成中

```json
{
  "id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "model": "doubao-seedance-2.0-fast",
  "status": "running",
  "created_at": 1779902412,
  "updated_at": 1779902468
}
```

### 成功

```json
{
  "id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "model": "doubao-seedance-2.0-fast",
  "status": "succeeded",
  "content": { "video_url": "https://r.amux.ai/cv/.../mp4-720p-....mp4" },
  "resolution": "720p",
  "duration": 8,
  "ratio": "16:9",
  "usage": { "completion_tokens": 173700, "total_tokens": 173700 },
  "created_at": 1779902412,
  "updated_at": 1779903017
}
```

### 失败

```json
{
  "id": "task_xxx",
  "model": "doubao-seedance-2.0-fast",
  "status": "failed",
  "error": { "code": "task_failed", "message": "具体失败原因" },
  "created_at": 1779902412,
  "updated_at": 1779902500
}
```

## 状态值

| status | 含义 |
| --- | --- |
| `queued` | 排队中（含已提交 / 未开始） |
| `running` | 生成中 |
| `succeeded` | 成功，`content.video_url` 可用 |
| `failed` | 失败，见 `error` |

<Callout type="warn">
**与火山官方的差异**：`id` 为网关任务 ID；`content.video_url` 经网关改写指向代理域名；`created_at` / `updated_at` 为 Unix 秒整型；火山官方部分字段（如 `seed`、`framespersecond`）在当前上游下不返回，会被省略。
</Callout>

## 轮询建议

创建后用返回的 `id` 轮询查询端点，直到 `status` 为 `succeeded` 或 `failed`，建议间隔 3 ~ 5 秒。
