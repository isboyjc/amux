title: Gemini 格式
description: 列出当前账户可用的所有模型 — Google Gemini 原生格式（`/v1beta/models`）
---

以 Google Gemini 原生格式返回当前 API 令牌可用的模型列表。该端点适合使用 Google 官方 SDK（`@google/genai`、`google-generativeai` 等）的应用场景。

| 项目 | 值 |
| --- | --- |
| **请求方法** | `GET` |
| **请求路径** | `/v1beta/models` |
| **完整 URL** | `https://api.amux.ai/v1beta/models` |
| **请求体** | 无 |
| **响应格式** | `application/json` |

<Callout type="info">
**端点说明**：

- `GET /v1beta/models` → 返回 **Gemini 原生格式**
- `GET /v1beta/openai/models` → 返回 **OpenAI 兼容格式**（同样的模型列表，但用 OpenAI 风格的响应结构 — `{ data: [...], object: "list" }`）

两条路径访问的是同一份模型列表，仅响应结构不同，方便不同 SDK 直接接入。
</Callout>

## 响应

模型列表的过滤逻辑与 [OpenAI 格式](./openai#响应) 完全一致 —— 受令牌白名单、用户分组、是否启用未配费率模型等设置约束。

```json
{
  "models": [
    {
      "name": "gemini-2.5-pro",
      "displayName": "gemini-2.5-pro"
    },
    {
      "name": "gemini-2.5-flash-image",
      "displayName": "gemini-2.5-flash-image"
    }
  ],
  "nextPageToken": null
}
```

## 请求示例

<Tabs items={['curl', 'Python', 'Node.js']}>
  <Tab value="curl">

```bash
curl "https://api.amux.ai/v1beta/models" \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

  </Tab>
  <Tab value="Python">

```python
import os
import httpx

response = httpx.get(
    "https://api.amux.ai/v1beta/models",
    headers={"Authorization": f"Bearer {os.environ['AMUX_API_KEY']}"},
)

for model in response.json()["models"]:
    print(model["name"])
```

  </Tab>
  <Tab value="Node.js">

```ts
const response = await fetch('https://api.amux.ai/v1beta/models', {
  headers: { Authorization: `Bearer ${process.env.AMUX_API_KEY}` },
});

const { models } = await response.json();
for (const m of models) {
  console.log(m.name);
}
```

  </Tab>

### 使用 x-goog-api-key 鉴权

```bash
curl "https://api.amux.ai/v1beta/models" \
  -H "x-goog-api-key: $AMUX_API_KEY"
```

### 使用 query key 鉴权

```bash
curl "https://api.amux.ai/v1beta/models?key=$AMUX_API_KEY"
```

## OpenAI 兼容路径（同一份列表）

`GET /v1beta/openai/models` 返回与 [`/v1/models` OpenAI 格式](./openai) 相同的响应结构，但走 Gemini 命名空间下，便于使用 Google SDK 时仍想拿到 OpenAI 风格的字段：

```bash
curl "https://api.amux.ai/v1beta/openai/models" \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

```json
{
  "success": true,
  "object": "list",
  "data": [
    {
      "id": "gemini-2.5-pro",
      "object": "model",
      "created": 1626777600,
      "owned_by": "google",
      "supported_endpoint_types": ["chat"]
    }
  ]
}
```

## 错误响应

错误响应结构与 [Gemini 文本聊天](../../text/gemini/chat#错误响应) 一致：

```json
{
  "error": {
    "code": 401,
    "message": "...",
    "status": "UNAUTHENTICATED"
  }
}
```

| HTTP 状态码 | 含义 |
| --- | --- |
| `200` | 请求成功 |
| `401` | API 密钥无效或缺失 |
| `500` | 服务端异常 |
