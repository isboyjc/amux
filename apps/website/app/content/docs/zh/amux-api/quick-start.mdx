只需三步，即可在几分钟内将 Amux API 接入您的项目或工具，调用市面主流大模型。

| 步骤 | 操作 | 预计耗时 |
| --- | --- | --- |
| 1 | 注册账号并完成充值 | ~2 分钟 |
| 2 | 创建 API 令牌 | ~30 秒 |
| 3 | 发送首次请求 | ~1 分钟 |

---

## 步骤 1：注册账号

<Steps>
  <Step>
    ### 访问注册页

    打开注册页面：[https://api.amux.ai/register](https://api.amux.ai/register?aff=GmHN)

    使用邮箱完成注册并设置密码。**注册成功即赠送 0.5 美元额度**，可用于测试调用平台所有可用模型。
  </Step>

  <Step>
    ### 登录控制台

    使用邮箱密码登录 [https://api.amux.ai](https://api.amux.ai)，可在控制台首页查看账户余额、消费记录与请求统计。
  </Step>

  <Step>
    ### 完成充值

    Amux API 采用 **按 Token 计费**，无月费、无最低消费，余额永久有效。可选择以下任一方式充值：

    **线上支付（推荐 · 即时到账）**

    平台采用 Stripe 聚合支付，支持 **银联、信用卡（Visa / Mastercard / 美运）、支付宝、微信、Stripe 钱包余额** 等多种支付渠道，付款后即时到账。如需开具 **Stripe 平台 Invoice / Receipt**，请联系客服开具。

    <Callout type="info">
      平台线上支付仅支持开具 **Stripe 平台 Invoice / Receipt**。如需 **国内电子增值税发票 / 增值税专用发票**，请联系客服使用 **线下对公转账** 方式充值。
    </Callout>

    **线下对公转账（企业用户与个人开发者均可）**

    如需开具国内电子增值税发票、增值税专用发票，或需要公司报销凭证，请通过线下对公转账方式充值。请联系客服对接打款信息与发票事宜。
  </Step>

  <Step>
    ### 自动升级 VIP 用户分组

    **累计充值满 20 美元，将自动升级至 VIP 分组**，享受以下权益：

    - 解锁更多 **高级稳定渠道** 模型
    - 享受 VIP 分组的 **更低折扣**
    - 与平台活动用户分流，**保障付费用户的稳定调用体验**

    <Callout type="info">
      此分组机制旨在让平台限时活动不会影响付费用户的服务质量。VIP 分组升级在累计充值达标后自动生效，无需手动申请。
    </Callout>
  </Step>
</Steps>

## 步骤 2：创建 API 令牌

<Steps>
  <Step>
    ### 进入令牌页

    登录 [https://api.amux.ai](https://api.amux.ai)，在左侧导航点击 **令牌**，然后点击 **创建令牌**。
  </Step>

  <Step>
    ### 命名并配置

    为令牌命名（建议按用途区分，例如 `dev`、`prod`、`cursor`、`claude-code`）。可根据需要设置令牌的额度上限、过期时间等。
  </Step>

  <Step>
    ### 创建并复制

    点击 **创建** 后，**立即复制并妥善保存** 生成的令牌字符串。

    <Callout type="warn">
      **令牌安全提醒**：

      - 令牌等同于账户访问凭证，一旦泄露请立即在控制台删除并重新创建
      - 切勿将令牌提交到 GitHub 等公共代码仓库
      - 推荐使用环境变量（如 `AMUX_API_KEY`）存储令牌，避免硬编码到代码中
    </Callout>
  </Step>
</Steps>

## 步骤 3：发送首次请求

Amux API **完全兼容 OpenAI API 格式**，您可以直接使用 OpenAI 官方 SDK，仅需替换 `Base URL` 与 `API Key` 即可。

### 配置参数

| 设置 | 值 |
| --- | --- |
| **Base URL** | `https://api.amux.ai/v1` |
| **API Key** | 步骤 2 中创建的 API 令牌 |
| **接口路径** | `/chat/completions`、`/embeddings`、`/images/generations` 等 |

### 调用示例

<Tabs items={['curl', 'Python', 'Node.js', '流式输出']}>
  <Tab value="curl">

```bash
curl https://api.amux.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $AMUX_API_KEY" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
  }'
```

  </Tab>
  <Tab value="Python">

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.amux.ai/v1",
    api_key=os.environ["AMUX_API_KEY"],
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[
        {"role": "user", "content": "你好，请介绍一下你自己"}
    ],
)

print(response.choices[0].message.content)
```

  </Tab>
  <Tab value="Node.js">

```ts
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.amux.ai/v1',
  apiKey: process.env.AMUX_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'gpt-5.4',
  messages: [{ role: 'user', content: '你好，请介绍一下你自己' }],
});

console.log(response.choices[0].message.content);
```

  </Tab>
  <Tab value="流式输出">

```ts
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.amux.ai/v1',
  apiKey: process.env.AMUX_API_KEY,
});

const stream = await client.chat.completions.create({
  model: 'gpt-5.4',
  messages: [{ role: 'user', content: '写一首关于春天的诗' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}
```

  </Tab>
</Tabs>

<Callout type="info">
推荐通过环境变量管理 API 令牌：

```bash
export AMUX_API_KEY="your-api-token"
```

这样可避免在代码中泄露密钥，也方便在开发 / 测试 / 生产环境之间切换。
</Callout>

## 配合 AI 工具使用

Amux API 兼容任何支持 OpenAI API 格式的工具，只需将工具的 Base URL 指向 `https://api.amux.ai/v1`，并填入您的 API 令牌即可。

| 工具 | Base URL 设置 | API Key 设置 |
| --- | --- | --- |
| **Cursor** | 覆盖 OpenAI Base URL | API 令牌 |
| **Claude Code** | 通过 Amux Desktop C/S 代理 | API 令牌 |
| **VS Code (Continue)** | 自定义提供商 Base URL | API 令牌 |
| **OpenClaw** | 自定义供应商 Base URL | API 令牌 |
| **Amux Desktop** | 内置集成（即将推出） | API 令牌 |

详见各集成指南了解具体配置步骤。

## 常见问题

<Accordions>
  <Accordion title="注册后送多少额度？可以用来做什么？">
    注册成功后赠送 **0.5 美元** 测试额度，可用于体验平台所有可用模型与接口能力，建议用于功能验证与小规模测试，不建议用于生产环境调用。
  </Accordion>

  <Accordion title="支持哪些充值方式？">
    平台采用 Stripe 聚合支付，线上支持 **银联、信用卡、支付宝、微信、Stripe 钱包** 等多种渠道，付款后即时到账。如需开具国内电子增值税发票或增值税专用发票，请通过 **线下对公转账** 方式充值，详见上方 [联系客服](#联系客服) 章节。
  </Accordion>

  <Accordion title="VIP 用户分组是什么？如何升级？">
    **累计充值满 20 美元** 即可自动升级至 VIP 分组，无需手动申请。升级后可访问更多高级稳定渠道模型，享受 VIP 分组的更低折扣，且不会受到平台限时活动用户的影响。
  </Accordion>

  <Accordion title="如何开具发票？">
    - **Stripe 平台 Invoice / Receipt**：使用线上 Stripe 充值后，联系客服开具
    - **国内电子增值税发票 / 增值税专用发票**：需通过线下对公转账方式充值，并联系客服对接打款与发票事宜

    联系方式详见上方 [联系客服](#联系客服) 章节。
  </Accordion>

  <Accordion title="调用失败如何排查？">
    1. 确认 `Base URL` 已正确指向 Amux API。**注意：不同 SDK / 工具对 `/v1` 后缀的处理方式不同** —— 部分 SDK（如 OpenAI 官方 SDK）会自动在 Base URL 后追加路径，需要填写带 `/v1` 的 `https://api.amux.ai/v1`；而部分客户端会要求填写不带后缀的 `https://api.amux.ai`，由其自行拼接接口路径。请参考所用工具的文档确认
    2. 确认 `Authorization` 头格式为 `Bearer <你的 API Token>`
    3. 检查账户余额是否充足
    4. 在控制台 **日志** 页面查看具体错误信息
  </Accordion>

  <Accordion title="令牌泄露怎么办？">
    立即在控制台 **令牌** 页面删除该令牌并新建一个，并同步更新所有使用该令牌的应用配置。建议为不同环境与项目使用不同的令牌，以缩小泄露后的影响范围。
  </Accordion>

  <Accordion title="如何控制成本？">
    控制台 **用量** 页面提供按令牌、按模型的消耗明细。建议为每个令牌设置 **额度上限** 与 **过期时间**，避免单个令牌泄露或失控调用导致的超额消费。
  </Accordion>

  <Accordion title="支持哪些 API 能力？">
    Chat Completions、Embeddings、Image Generation、Function Calling、流式响应（SSE）等主流能力均已支持，详见 [文本 API 文档](/zh/docs/amux-api/text/openai/chat-completions)、[图像 API 文档](/zh/docs/amux-api/image/openai/generations) 与 [视频 API 文档](/zh/docs/amux-api/video/create-task)。
  </Accordion>
</Accordions>
