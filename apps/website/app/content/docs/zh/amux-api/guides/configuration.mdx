## 概述

Amux API Platform 基于 [New API](https://github.com/QuantumNous/new-api) 构建，提供基于 Web 的管理面板来配置渠道、令牌和模型路由。

## 渠道管理

渠道代表与上游大模型提供商的连接。每个渠道有自己的 API 密钥、基础 URL 和支持的模型列表。

### 添加渠道

1. 登录管理面板
2. 导航到 **渠道** → **添加渠道**
3. 配置渠道：

| 字段 | 描述 |
| --- | --- |
| **名称** | 渠道的显示名称 |
| **类型** | 提供商类型（OpenAI、Claude、Gemini 等） |
| **基础 URL** | 提供商的 API 端点 |
| **API 密钥** | 提供商的认证密钥 |
| **模型** | 通过此渠道可用的模型列表 |
| **优先级** | 路由优先级（越高越优先） |
| **权重** | 同优先级内的负载均衡权重 |

### 支持的提供商类型

- OpenAI (GPT-4、GPT-4o、o3-mini 等)
- Anthropic (Claude 4 Sonnet、Claude 4 Opus 等)
- Google Gemini (Gemini 2.5 Pro、Gemini 2.5 Flash 等)
- DeepSeek (DeepSeek-V3、DeepSeek-R1 等)
- Moonshot (Kimi)
- 智谱 AI (GLM-4)
- 以及更多...

## 模型路由

Amux API Platform 支持多种策略的智能模型路由：

### 基于优先级的路由

优先使用优先级更高的渠道。如果高优先级渠道失败，系统自动切换到下一个可用渠道。

### 加权负载均衡

对于相同优先级的渠道，请求根据配置的权重进行分发。

### 模型映射

将自定义模型名称映射到特定的提供商模型：

| 传入模型 | 路由至 |
| --- | --- |
| `gpt-4` | OpenAI GPT-4 渠道 |
| `claude` | Anthropic Claude 渠道 |
| `fast` | DeepSeek 渠道 (更低成本) |

## 系统设置

### 常规设置

| 设置 | 描述 |
| --- | --- |
| **服务器地址** | API Platform 的公网 URL |
| **重试次数** | 渠道失败时的重试次数 |
| **显示令牌** | 在用户仪表盘上显示令牌 |
| **检查频率** | 渠道健康检查间隔 |

### 计费设置

| 设置 | 描述 |
| --- | --- |
| **额度模式** | 基于 Token 或基于请求的计费 |
| **模型定价** | 每个模型的输入/输出 Token 价格 |
| **缓存计费** | 是否对缓存的 Token 计费 |

## 环境变量

部署时的关键环境变量：

```bash
# 数据库
SQL_DSN=root:password@tcp(localhost:3306)/new-api

# 服务器
PORT=3000
TZ=Asia/Shanghai

# Redis（可选，用于分布式部署）
REDIS_CONN_STRING=redis://localhost:6379

# 会话密钥
SESSION_SECRET=your-random-secret
```
