title: 在 OpenClaw 中使用
description: 将 OpenClaw 连接到 Amux API Platform
---

[OpenClaw](https://openclaw.ai) 是一个开源的 AI Agent，具备丰富的 CLI 功能。它支持自定义供应商，可以方便地接入 Amux API Platform。

## 前提条件

- 已安装 OpenClaw（[安装指南](/zh/docs/amux-api/guides/install-openclaw)）
- 拥有 Amux API Platform 账号和 API 令牌（[快速开始](/zh/docs/amux-api/quick-start)）

## 配置

### 方式一：交互式设置

运行引导向导并选择自定义供应商：

```bash
openclaw onboard \
  --auth-choice custom-api-key \
  --custom-base-url "https://amux.ai/v1" \
  --custom-model-id "gpt-5.4" \
  --custom-api-key "your-amux-api-token" \
  --custom-compatibility openai
```

### 方式二：配置文件

编辑 `~/.openclaw/openclaw.json`，将 Amux API 添加为自定义供应商：

```json
{
  "models": {
    "providers": {
      "amux": {
        "baseUrl": "https://amux.ai/v1",
        "apiKey": "your-amux-api-token",
        "api": "openai-completions",
        "models": [
          {
            "id": "gpt-5.4",
            "name": "GPT-5.4",
            "contextWindow": 128000,
            "maxTokens": 16384
          },
          {
            "id": "grok-3",
            "name": "Grok 3",
            "contextWindow": 131072,
            "maxTokens": 16384
          },
          {
            "id": "MiniMax-M2.5",
            "name": "MiniMax M2.5",
            "contextWindow": 1000000,
            "maxTokens": 16384
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "amux/gpt-5.4"
      }
    }
  }
}
```

### 方式三：环境变量

```bash
export CUSTOM_API_KEY="your-amux-api-token"
openclaw onboard \
  --non-interactive \
  --auth-choice custom-api-key \
  --custom-base-url "https://amux.ai/v1" \
  --custom-model-id "gpt-5.4" \
  --custom-compatibility openai
```

## 验证

检查供应商是否配置正确：

```bash
openclaw models status
```

## 使用

启动交互式会话：

```bash
cd /path/to/your/project
openclaw
```

## 切换模型

你可以随时在 Amux API 模型之间切换。如果在供应商配置中定义了多个模型，可以设置默认模型：

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "amux/gpt-5.4"
      }
    }
  }
}
```

或通过 CLI 切换模型：

```bash
openclaw models set amux/grok-3
```

## 注意事项

- Amux API Platform 兼容 OpenAI，在供应商配置中使用 `"api": "openai-completions"`
- OpenClaw 的所有功能（Agents、工具、沙箱执行）均可正常使用
- 可用模型取决于你的 Amux API 账号和额度
- 对于敏感的 API 令牌，可在配置中使用 `${ENV_VAR}` 语法或密钥引用
