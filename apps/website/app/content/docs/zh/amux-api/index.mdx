## 什么是 Amux API？

Amux API 是一个统一、稳定的企业级大模型接口网关。我们目前支持市面上所有主流的大模型供应商，提供标准化的 API 集成、按量计费，企业可开具增值税发票。

### 平台状态

平台稳定运行中，**20+ 家企业已接入使用**。

### 平台定位

Amux API 提供统一的 AI 模型 API 接入能力，面向企业系统集成、软件开发及业务自动化场景：

- **统一 API 接口**：一套标准接口对接多个 AI 模型服务商
- **面向企业与开发者**：用于系统集成、应用开发、内部工具
- **技术服务定位**：不参与模型训练、不干预生成逻辑、不存储用户内容
- **工程级稳定性**：99.9% 可用性，面向高并发企业级调用场景

### 核心优势

- **企业认证**：支持企业对公转账，开具增值税发票
- **技术支持**：中文技术支持，微信群实时响应
- **数据安全**：不存储用户请求内容，参考行业安全标准
- **灵活计费**：按 Token 计费，无月费，充值秒到账

### 使用平台

如果您已经拥有账号并成功创建了 API 令牌，平台的 Base URL 为：

```
https://api.amux.ai
```

您可以使用此 Base URL 和您在平台创建的 API Token 接入包含 **Amux Desktop** 在内的任何支持 OpenAI API 格式的 AI Agent 项目。

### 与其他 Amux 产品的关系

- **[Amux Desktop](/zh/docs/desktop)**：个人桌面大模型客户端，内置网关服务。未来 Desktop 将内置支持 Amux API 的服务集成，打通 Web 端 API 网关与本地客户端。目前您已经可以通过 Amux API 搭配 Desktop 的 C/S 代理模块，动态切换 Claude Code 等工具使用任意模型。
- **[Amux LLM Bridge](/zh/docs/llm-bridge)**：Amux Desktop 使用的核心适配器转换引擎，负责本地的 LLM 提供商格式翻译。
