## 什么是 Amux API Platform？

Amux API Platform 是一个独立、统一的大模型接口网关平台，基于开源项目 [New API](https://github.com/QuantumNous/new-api) 上层构建改造。平台已接入多家上游提供商，提供多家大模型提供商 API 的集中管理与分发。

用户可以在平台注册登录，创建 API 令牌，即可通过统一的 API 端点使用丰富的 AI 模型。

后续 **Amux Desktop** 将内置支持 Amux API Platform 的服务集成，打通 Web 端 API 平台与本地客户端的快速集成。

### 平台状态

Amux API Platform 目前**限时开放注册**。注册后，部分内测用户将获得兑换码以获得额度体验此平台。

### 支持的模型

Amux API Platform 目前支持：

| 提供商 | 模型 |
| --- | --- |
| **OpenAI** | GPT-5.4 及 GPT 全系模型 |
| **xAI** | Grok 全系模型（文本、图像、视频） |
| **MiniMax** | M2.5 及 M 全系模型 |

我们将逐步扩充上游服务商，以支持 **Claude**、**Gemini** 在内的所有优质模型。

### 核心特性

- **统一 API 网关**：通过单一的 OpenAI 兼容 API 端点访问多家大模型提供商
- **用户注册与令牌管理**：注册账号、创建 API 令牌、管理使用量
- **额度与计费**：基于积分的额度系统，透明的用量追踪
- **多提供商路由**：智能路由，支持故障转移、负载均衡和基于优先级的渠道选择
- **流式支持**：全面支持跨所有提供商的 SSE 流式响应
- **OpenAI 兼容**：兼容任何支持 OpenAI API 格式的客户端

### 使用平台

如果您已经拥有账号并成功创建了 API 令牌，平台的 Base URL 为：

```
https://amux.ai
```

您可以使用此 Base URL 和您在平台创建的 API Token 接入包含 **Amux Desktop** 在内的任何支持 OpenAI API 格式的 AI Agent 项目。

### 架构

```
      ▼      ▼      ▼
   OpenAI   xAI   MiniMax   Claude(即将)  Gemini(即将)  ...
```

### 与其他 Amux 产品的关系

- **[Amux Desktop](/zh/docs/desktop)**：个人桌面大模型客户端，内置网关服务。未来 Desktop 将内置支持 Amux API Platform，打通 Web 端 API 平台与本地客户端。目前您已经可以通过 Amux API 搭配 Desktop 的 C/S 代理模块，动态切换 Claude Code 等工具使用任意模型。
- **[Amux LLM Bridge](/zh/docs/llm-bridge)**：Amux Desktop 使用的核心适配器转换引擎，负责本地的 LLM 提供商格式翻译。
