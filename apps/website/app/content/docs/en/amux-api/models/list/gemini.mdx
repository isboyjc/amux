title: Gemini Format

Return the model list in Google Gemini's native format. Best when using the official Google SDKs (`@google/genai`, `google-generativeai`, etc.).

| Field | Value |
| --- | --- |
| **Method** | `GET` |
| **Path** | `/v1beta/models` |
| **Full URL** | `https://api.amux.ai/v1beta/models` |
| **Body** | none |
| **Response format** | `application/json` |

<Callout type="info">
**Endpoints**:

- `GET /v1beta/models` → returns the **Gemini native format**
- `GET /v1beta/openai/models` → returns the **OpenAI-compatible format** (same model list, but OpenAI-style response — `{ data: [...], object: "list" }`)

Both paths read the same model list; only the response shape differs, so different SDKs can plug in directly.
</Callout>

## Response

The model list is filtered using the same logic as the [OpenAI format](./openai#response) — by token whitelist, user group, and unset-rate model settings.

```json
{
  "models": [
    {
      "name": "gemini-2.5-pro",
      "displayName": "gemini-2.5-pro"
    },
    {
      "name": "gemini-2.5-flash-image",
      "displayName": "gemini-2.5-flash-image"
    }
  ],
  "nextPageToken": null
}
```

<TypeTable
  type={{
    models: {
      type: 'array<GeminiModel>',

    },
    nextPageToken: {
      type: 'string | null',
      description: 'Pagination token. amux-api currently always returns `null` (no pagination — single response with the full list).',
    },
  }}
/>

## Examples

<Tabs items={['curl', 'Python', 'Node.js']}>
  <Tab value="curl">

```bash
curl "https://api.amux.ai/v1beta/models" \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

  </Tab>
  <Tab value="Python">

```python
import os
import httpx

response = httpx.get(
    "https://api.amux.ai/v1beta/models",
    headers={"Authorization": f"Bearer {os.environ['AMUX_API_KEY']}"},
)

for model in response.json()["models"]:
    print(model["name"])
```

  </Tab>
  <Tab value="Node.js">

```ts
const response = await fetch('https://api.amux.ai/v1beta/models', {
  headers: { Authorization: `Bearer ${process.env.AMUX_API_KEY}` },
});

const { models } = await response.json();
for (const m of models) {
  console.log(m.name);
}
```

### Authenticate via x-goog-api-key

```bash
curl "https://api.amux.ai/v1beta/models" \
  -H "x-goog-api-key: $AMUX_API_KEY"
```

### Authenticate via query key

```bash
curl "https://api.amux.ai/v1beta/models?key=$AMUX_API_KEY"
```

## OpenAI-Compatible Path (same list)

`GET /v1beta/openai/models` returns the same shape as [`/v1/models` in OpenAI format](./openai), but lives under the Gemini namespace — convenient when using a Google SDK while still preferring OpenAI-style fields:

```bash
curl "https://api.amux.ai/v1beta/openai/models" \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

```json
{
  "success": true,
  "object": "list",
  "data": [
    {
      "id": "gemini-2.5-pro",
      "object": "model",
      "created": 1626777600,
      "owned_by": "google",
      "supported_endpoint_types": ["chat"]
    }
  ]
}
```

## Error Response

The error shape matches [Gemini Text Chat](../../text/gemini/chat#error-response):

```json
{
  "error": {
    "code": 401,
    "message": "...",
    "status": "UNAUTHENTICATED"
  }
}
```

| HTTP Status | Meaning |
| --- | --- |
| `200` | Success |
| `401` | Missing or invalid API key |
| `500` | Server-side error |
