List the models available to the current API token. amux-api **auto-detects the response format from request headers** at `/v1/models`, so this single endpoint can serve OpenAI, Anthropic, and Gemini clients.

| Field | Value |
| --- | --- |
| **Method** | `GET` |
| **Path** | `/v1/models` |
| **Full URL** | `https://api.amux.ai/v1/models` |
| **Body** | none |
| **Response format** | `application/json` |

<Callout type="info">
**Response format auto-detection** (`router/relay-router.go:23-32`):

- Both `x-api-key` and `anthropic-version` headers present → **Anthropic format**
- `x-goog-api-key` header or `?key=` query parameter present → routes to Gemini Retrieve (prefer [`/v1beta/models`](./gemini))
- Otherwise → **OpenAI format** (default)
</Callout>

## Response

The returned model list is filtered by:

- The current API token's **allowed-model whitelist** (if `model_limit` is set on the token)
- Models enabled for the current user's group (or token-specified group)
- Whether **models without configured rates** are included — controlled by system setting `SelfUseModeEnabled` and user setting `AcceptUnsetRatioModel`

```json
{
  "data": [
    {
      "id": "claude-sonnet-4-5",
```

## Examples

<Tabs items={['curl', 'Python', 'Node.js']}>
  <Tab value="curl">

```bash
curl https://api.amux.ai/v1/models \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

  </Tab>
  <Tab value="Python">

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.amux.ai/v1",
    api_key=os.environ["AMUX_API_KEY"],
)

models = client.models.list()
for m in models.data:
    print(m.id)
```

  </Tab>

```ts
const client = new OpenAI({
  baseURL: 'https://api.amux.ai/v1',

const models = await client.models.list();

}
```

### Fetching in Anthropic Format

```bash
curl https://api.amux.ai/v1/models \
  -H "x-api-key: $AMUX_API_KEY" \
  -H "anthropic-version: 2023-06-01"
```

## Retrieve a Single Model

amux-api also supports retrieving a single model:

```
GET /v1/models/{model}
```

```bash
curl https://api.amux.ai/v1/models/gpt-5.4 \
  -H "Authorization: Bearer $AMUX_API_KEY"
```

Returns a single Model object. The same `x-api-key` + `anthropic-version` header trick switches the response to Anthropic format.

## Error Response

```json
{
  "error": {
    "message": "...",
    "type": "invalid_request_error",
    "code": "invalid_api_key"
  }
}
```

| HTTP Status | Meaning |
| --- | --- |
| `200` | Success |
| `401` | Missing or invalid API key |
| `404` | When retrieving a single model — `model` not found |
| `500` | Server-side error |
