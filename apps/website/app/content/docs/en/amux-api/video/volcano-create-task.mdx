title: Create Video Generation Task (Volcengine v3)
description: Volcengine Ark (Seedance) v3 protocol — create a video generation task. Request path / body align with Volcengine's official v3; responses are gateway-normalized. Supports text, reference images, first/last frames, reference video, and reference audio
---

amux-api is compatible with the **Volcengine Ark (Seedance) v3 protocol** and exposes video task endpoints identical to Volcengine's official contract. This page covers the **create task** endpoint; for status queries see [Get Task Status (Volcengine v3)](./volcano-get-task).

<Callout type="info">
**When to use this format**: Volcengine native SDKs / existing v3 integrations work by just pointing `base_url` at amux. For a vendor-neutral schema, use [Create Video Generation Task (universal)](./create-task) instead.
</Callout>

## General

| Item | Value |
| --- | --- |
| **Method** | `POST` |
| **Path** | `/api/v3/contents/generations/tasks` |
| **Full URL** | `https://api.amux.ai/api/v3/contents/generations/tasks` |
| **Auth** | `Authorization: Bearer <AMUX_API_KEY>` |
| **Request format** | `application/json` |
| **Response format** | `application/json` |
| **Task isolation** | Tasks are isolated per key owner; you can only query tasks you created |

**Auth failure response** (HTTP 401):

```json
{ "error": { "code": "", "message": "Invalid token (request id: ...)", "type": "new_api_error" } }
```

## Request Parameters

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `model` | Yes | string | Model name (depends on the models enabled at the gateway), e.g. `doubao-seedance-2.0`, `doubao-seedance-2.0-fast` |
| `content` | Yes | object[] | Multimodal input array, with at least one `type: "text"` item; see [content Types](#content-types) |
| `ratio` | No | string | Aspect ratio, one of `1:1` / `16:9` / `9:16` / `3:4` / `4:3` / `21:9` |
| `duration` | No | number | Desired duration (0–16s), default `0` (auto) |
| `resolution` | No | string | Resolution, `720p` / `1080p`; `doubao-seedance-2.0-fast` does not support `1080p` |
| `seed` | No | integer | Random seed |
| `generate_audio` | No | boolean | Whether to generate audio synced to the video, default `true`. When `true`, the model auto-generates speech / SFX / BGM (wrap dialogue in double quotes); `false` outputs a silent video |
| `watermark` | No | boolean | Whether to add a watermark, default `false` |
| `return_last_frame` | No | boolean | Whether to return the last frame as an image, default `false` |
| `callback_url` | No | string | Callback URL invoked when the task completes |
| `tools` | No | object[] | Whether to enable web search; currently only `[{ "type": "web_search" }]` is supported |

<Callout type="warn">
**Upstream parameters the gateway does not currently support**: `trace_id`, `rpf_auto_detect`. Even if sent, they are dropped by the gateway and not forwarded upstream (`rpf_auto_detect` therefore always uses the upstream default `true`, i.e. automatic face detection).
</Callout>

## content Types

Supported combinations: `text` / `text(optional)+image` / `text(optional)+video` / `text(optional)+image+audio` / `text(optional)+image+video` / `text(optional)+video+audio` / `text(optional)+image+video+audio`.

**Text** (`type: "text"`)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Fixed `text` |
| `text` | string | Yes | Prompt describing the desired video |

**Image** (`type: "image_url"`)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Fixed `image_url` |
| `image_url` | object | Yes | `{ "url": "accessible image URL" }` |
| `role` | string | No | Usage. **Image-to-video (first frame)**: 1 image, `role` = `first_frame` or omitted; **first/last frame**: 2 images, required, first `first_frame`, last `last_frame`; **reference**: every reference image is `reference_image` |

**Video** (`type: "video_url"`)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Fixed `video_url` |
| `video_url` | object | Yes | `{ "url": "accessible video URL" }` |
| `role` | string | No | Currently only `reference_video` is supported |

**Audio** (`type: "audio_url"`)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Fixed `audio_url` |
| `audio_url` | object | Yes | `{ "url": "accessible audio URL" }` |
| `role` | string | No | Currently only `reference_audio` is supported |

## Examples

### Text-to-Video (minimal)

```bash
curl https://api.amux.ai/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $AMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0-fast",
    "content": [
      { "type": "text", "text": "A cat leaping on a sunny meadow" }
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p"
  }'
```

### Multimodal (reference image + video + audio)

```bash
curl https://api.amux.ai/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $AMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0",
    "content": [
      { "type": "text", "text": "Use the first-person framing from video 1 throughout; first frame is image 1, last frame freezes on image 2..." },
      { "type": "image_url", "image_url": { "url": "https://example.com/pic1.jpg" }, "role": "reference_image" },
      { "type": "image_url", "image_url": { "url": "https://example.com/pic2.jpg" }, "role": "reference_image" },
      { "type": "video_url", "video_url": { "url": "https://example.com/video1.mp4" }, "role": "reference_video" },
      { "type": "audio_url", "audio_url": { "url": "https://example.com/audio1.mp3" }, "role": "reference_audio" }
    ],
    "generate_audio": true,
    "ratio": "16:9",
    "duration": 11
  }'
```

### Image-to-Video (first/last frame)

```bash
curl https://api.amux.ai/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $AMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0",
    "content": [
      { "type": "text", "text": "Camera slowly pulls back from a close-up" },
      { "type": "image_url", "image_url": { "url": "https://example.com/first.jpg" }, "role": "first_frame" },
      { "type": "image_url", "image_url": { "url": "https://example.com/last.jpg" },  "role": "last_frame" }
    ],
    "duration": 5,
    "resolution": "1080p"
  }'
```

## Response

**HTTP 200:**

```json
{
  "id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "task_id": "task_hPWLhwc7lBKHFH4scfvQfI4xaND2XFHp",
  "object": "video",
  "model": "doubao-seedance-2.0-fast",
  "status": "queued",
  "progress": 0,
  "created_at": 1779902412
}
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | **Gateway task ID** — use it to query status later |
| `task_id` | string | Same as `id` (compatibility field) |
| `object` | string | Fixed `video` |
| `model` | string | Model name |
| `status` | string | Always `queued` right after creation |
| `progress` | int | Progress, `0` at creation |
| `created_at` | int | Creation time (Unix seconds) |

<Callout type="warn">
**Difference from Volcengine official**: Volcengine's official create endpoint returns only `{"id": "cgt-xxx"}`; this gateway returns the structure above, and `id` is a **gateway task ID** (`task_xxx`), not Volcengine's `cgt-xxx`. Clients read `id` and use it to query.
</Callout>
