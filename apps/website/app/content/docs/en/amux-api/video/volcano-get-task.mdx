Query task status using the `id` returned by [Create Video Generation Task (Volcengine v3)](./volcano-create-task). Returns the **official Volcengine v3 task structure** (gateway-normalized).

## General

| Item | Value |
| --- | --- |
| **Method** | `GET` |
| **Path** | `/api/v3/contents/generations/tasks/{task_id}` |
| **Full URL** | `https://api.amux.ai/api/v3/contents/generations/tasks/{task_id}` |
| **Auth** | `Authorization: Bearer <AMUX_API_KEY>` |
| **Request body** | None |
| **Response format** | `application/json` |
| **Task isolation** | You can only query tasks you created |

`{task_id}` is the `id` returned by the create endpoint.

## Response Fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Gateway task ID |
| `model` | string | Model name |
| `status` | string | `queued` / `running` / `succeeded` / `failed` |
| `content` | object | Present on success, `{ "video_url": "..." }` |
| `content.video_url` | string | Video URL (sanitized / proxy-rewritten by the gateway; the upstream direct link is not exposed) |
| `resolution` | string | Resolution, e.g. `720p` |
| `duration` | int | Duration (seconds) |
| `ratio` | string | Aspect ratio, e.g. `16:9` |
| `usage.completion_tokens` | int | Generated tokens |
| `usage.total_tokens` | int | Total tokens |
| `error` | object | Present on failure, `{ "code": "...", "message": "..." }` |
| `created_at` | int | Creation time (Unix seconds) |
| `updated_at` | int | Update time (Unix seconds) |

> Not-ready / not-applicable fields are omitted (no `content` / `usage` while generating; no `error` on success).

### Failed

```json
{
  "id": "task_xxx",
  "model": "doubao-seedance-2.0-fast",
  "status": "failed",
  "error": { "code": "task_failed", "message": "Specific failure reason" },
  "created_at": 1779902412,
  "updated_at": 1779902500
}
```

## Status Values

| status | Meaning |
| --- | --- |
| `queued` | Queued (submitted / not yet started) |
| `running` | Generating |
| `succeeded` | Done, `content.video_url` available |
| `failed` | Failed, see `error` |

<Callout type="warn">
**Difference from Volcengine official**: `id` is a gateway task ID; `content.video_url` is rewritten to point at a proxy domain; `created_at` / `updated_at` are Unix-second integers; some Volcengine official fields (e.g. `seed`, `framespersecond`) are not returned by the current upstream and are omitted.
</Callout>

## Polling Tips

After creation, poll the query endpoint with the returned `id` until `status` is `succeeded` or `failed` — every 3–5 seconds is recommended.
