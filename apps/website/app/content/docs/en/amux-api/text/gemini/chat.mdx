title: Text Chat
description: Gemini-native generateContent / streamGenerateContent endpoint — fully Google Gemini API compatible
---

Proxies native Gemini API requests under the path `/v1beta/models/{model}:{action}`. Fully compatible with the Google Gemini protocol — supports text generation, multi-turn conversation, streaming, function calling, built-in tools (Google Search / URL Context / Code Execution), and Extended Thinking.

| Field | Value |
| --- | --- |
| **Method** | `POST` |
| **Path** | `/v1beta/models/{model}:generateContent`<br/>`/v1beta/models/{model}:streamGenerateContent?alt=sse` |
| **Full URL** | `https://api.amux.ai/v1beta/models/gemini-2.5-pro:generateContent` |
| **Request format** | `application/json` |
| **Response format** | JSON, or SSE for the streaming action / `?alt=sse` |

<Callout type="info">
This endpoint is fully aligned with the Google Gemini API. You can use the official Google SDK (`@google/generative-ai` / `google-generativeai`) directly — just override the base URL. For multimodal usage (image / PDF / audio / video), see [Media Understanding](./media).
</Callout>

## Streaming

Switch the action to `streamGenerateContent` and append `?alt=sse`. The response is an SSE stream:

```
data: {"candidates":[{"content":{"role":"model","parts":[{"text":"Amux"}]},"index":0}]}

data: {"candidates":[{"content":{"role":"model","parts":[{"text":" API"}]},"index":0}]}

data: {"candidates":[{"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":24,"candidatesTokenCount":18,"totalTokenCount":42}}
```

Each chunk's `candidates[].content.parts` carries the increment. `usageMetadata` is typically emitted in the final chunk.

<Callout type="info">
amux-api treats a request as streaming when **either** of the following is true:

1. The URL path contains `streamGenerateContent`, **or**
2. The query parameter `alt=sse` is present.
</Callout>

## Error Response

```json
{
  "error": {
    "code": 400,
    "message": "...",
    "status": "INVALID_ARGUMENT",
    "details": [...]
  }
}
```

| HTTP Status | Meaning |
| --- | --- |
| `200` | Success |
| `400` | Bad request parameters (`INVALID_ARGUMENT`) |
| `401` | Missing or invalid API key (`UNAUTHENTICATED`) |
| `403` | Permission denied (`PERMISSION_DENIED`) |
| `404` | Model not found (`NOT_FOUND`) |
| `429` | Rate limit triggered or insufficient balance (`RESOURCE_EXHAUSTED`) |
| `500` / `502` / `503` | Server-side error or upstream unavailable |
