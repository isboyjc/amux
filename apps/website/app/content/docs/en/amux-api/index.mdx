## What is Amux API?

Amux API is a unified, stable enterprise-grade LLM API gateway. We currently support all mainstream LLM providers on the market, offering standardized API integration, pay-as-you-go billing, and VAT invoices for enterprise customers.

### Platform Status

The platform is running stably with **20+ enterprises onboarded**.

### Platform Positioning

Amux API delivers unified AI model API access for enterprise system integration, software development, and business automation scenarios:

- **Unified API Interface**: One standardized interface to connect multiple AI model providers
- **Built for Enterprises and Developers**: Designed for system integration, application development, and internal tooling
- **Technical Service Focus**: Does not participate in model training, does not intervene in generation logic, does not store user content
- **Engineering-Grade Stability**: 99.9% availability, designed for high-concurrency enterprise-grade workloads

### Core Advantages

- **Enterprise Verification**: Supports enterprise wire transfers and VAT invoice issuance
- **Technical Support**: Chinese-language technical support with real-time response via WeChat groups
- **Data Security**: User request content is not stored; aligned with industry security standards
- **Flexible Billing**: Pay-per-token, no monthly fees, instant top-ups

### Using the Platform

If you already have an account and have created an API token, the platform's Base URL is:

```
https://api.amux.ai
```

You can use this Base URL along with your API token to connect to any AI Agent project that supports the OpenAI API format, including **Amux Desktop** and many other tools.

### Relationship with Other Amux Products

- **[Amux Desktop](/docs/desktop)**: A personal desktop LLM client with built-in gateway services. In a future release, Desktop will integrate Amux API support, bridging the Web-based API gateway with the local client. You can already use Amux API with Desktop's C/S proxy module to dynamically switch models for tools like Claude Code.
- **[Amux LLM Bridge](/docs/llm-bridge)**: The core adapter conversion engine used by Amux Desktop for local format translation between LLM providers.
