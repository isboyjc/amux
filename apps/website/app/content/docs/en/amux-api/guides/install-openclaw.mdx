[OpenClaw](https://openclaw.ai) is an open-source AI Agent with extensive CLI capabilities, supporting agents, tools, sandbox execution, and custom providers. Once installed, you can [use it with Amux API Platform](/docs/amux-api/guides/use-with-openclaw).

## System Requirements

| Requirement | Minimum |
| --- | --- |
| **OS** | macOS 11+, Linux (Ubuntu 20.04+, Debian 11+), Windows 10/11 (WSL2) |
| **Node.js** | 22+ |
| **Network** | Internet connection required |

## Installation

### Quick Install (Recommended)

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Automatically detects your platform and installs the appropriate binary.

### npm

```bash
npm install -g openclaw@latest
```

### Docker

```bash
docker run -it --rm openclaw/openclaw
```

## Verify Installation

```bash
openclaw --version
```

## Initial Setup

Run the onboarding wizard to configure your first provider:

```bash
openclaw onboard
```

Follow the prompts to select a provider and enter your API key. You can also set up using environment variables or configuration files.

### Using an API Key

```bash
openclaw onboard --auth-choice openai-api-key
```

Or for custom providers:

```bash
openclaw onboard --auth-choice custom-api-key \
  --custom-base-url "https://api.example.com/v1" \
  --custom-model-id "model-name" \
  --custom-api-key "your-key" \
  --custom-compatibility openai
```

## Quick Start

Navigate to your project and start OpenClaw:

```bash
cd /path/to/your/project
openclaw
```

Check provider status:

```bash
openclaw models status
```

## Configuration

All settings are stored in `~/.openclaw/openclaw.json`. Sensitive credentials can be stored in `~/.openclaw/.env`.

## Using with Amux API Platform

After installing OpenClaw, see [Use with OpenClaw](/docs/amux-api/guides/use-with-openclaw) to connect it to Amux API Platform and access GPT, Grok, MiniMax, and other models.
