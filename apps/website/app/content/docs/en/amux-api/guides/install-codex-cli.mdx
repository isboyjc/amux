[Codex CLI](https://github.com/openai/codex) is OpenAI's open-source AI coding agent that runs in your terminal. It features three safety modes (Suggest, Auto Edit, Full Auto) and uses OS-level sandboxing for security.

## System Requirements

| Requirement | Minimum |
| --- | --- |
| **OS** | macOS, Linux, Windows (via WSL) |
| **Node.js** | 18+ (for npm installation only) |
| **Network** | Internet connection required |
| **Account** | ChatGPT Plus/Pro/Team/Business/Edu/Enterprise, or OpenAI API key |

## Installation

### npm

```bash
npm install -g @openai/codex
```

### Homebrew (macOS)

```bash
brew install --cask codex
```

### GitHub Releases

Download platform-specific binaries (macOS Intel/Apple Silicon, Linux x86_64/arm64) from the [GitHub Releases](https://github.com/openai/codex/releases) page.

## Verify Installation

```bash
codex --version
```

## Authentication

### Option 1: ChatGPT Subscription (Recommended)

Run `codex` and select "Sign in with ChatGPT" — it will open your browser for authentication. No additional charges beyond your subscription.

```bash
codex
```

### Option 2: API Key

```bash
export OPENAI_API_KEY="sk-..."
codex
```

### Remote / SSH Access

For using Codex CLI over SSH, forward the auth port:

```bash
ssh -L 1455:localhost:1455 user@your-server
codex
```

## Quick Start

**Interactive session:**

```bash
codex
```

**Single command:**

```bash
codex "explain what this codebase does"
```

**Full auto mode:**

```bash
codex --full-auto "Run tests and fix failures"
```

## Safety Modes

| Mode | Description |
| --- | --- |
| **Suggest** | Suggestions only, no file modifications |
| **Auto Edit** | Auto-edits files, asks approval for commands |
| **Full Auto** | Complete automation, no approval needed |

Codex CLI uses OS-level sandboxing (macOS Seatbelt, Linux Landlock) with network blocked by default for safe execution.

## Using with Amux API Platform

After installing Codex CLI, see [Use with Codex](/docs/amux-api/guides/use-with-codex) to connect it to Amux API Platform.

You can also route Codex CLI through an [Amux Desktop proxy](/docs/desktop/guides/proxies) by setting the API base URL:

```bash
export OPENAI_BASE_URL="http://127.0.0.1:9527/proxies/{proxyPath}"
export OPENAI_API_KEY="sk-amux.xxx"
codex
```
