## System Requirements

| Platform | Requirement |
| --- | --- |
| **macOS** | macOS 10.15 (Catalina) or later, Intel or Apple Silicon |
| **Windows** | Windows 10 or later, 64-bit |
| **Linux** | Ubuntu 20.04+, Debian 11+, Fedora 36+, or equivalent |

## Download

Download the latest release from the [GitHub Releases](https://github.com/isboyjc/amux/releases) page.

| Platform | File | Architecture | Download |
| --- | --- | --- | --- |
| macOS | `amux-desktop-x.x.x.dmg` | Universal (Intel + Apple Silicon) | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Windows | `amux-desktop-x.x.x-setup.exe` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Linux | `amux-desktop-x.x.x.AppImage` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |
| Linux (Debian) | `amux-desktop-x.x.x.deb` | x64 | [GitHub Releases](https://github.com/isboyjc/amux/releases) |

## Installation Steps

### macOS

1. Open the downloaded `.dmg` file
2. Drag **Amux Desktop** to the **Applications** folder

{/* IMAGE: macOS installation - drag to Applications */}

#### macOS Security Tips

Since the app is not notarized by Apple, macOS may show a **"damaged"** or **"can't be opened"** error. Here are three methods to fix it:

**Method 1: Right-click to Open**

1. Right-click (or Control+Click) on the app icon
2. Select **"Open"** from the menu
3. Click **"Open"** in the security dialog

**Method 2: System Settings**

1. Try to open the app (it will be blocked)
2. Go to **System Settings > Privacy & Security**
3. Scroll down to find the "Amux was blocked" message
4. Click **"Open Anyway"**
5. Click **"Open"** in the confirmation dialog

**Method 3: Remove Quarantine (Terminal)**

```bash
xattr -dr com.apple.quarantine /Applications/Amux.app
```

If the app is in your Downloads folder:

```bash
xattr -dr com.apple.quarantine ~/Downloads/Amux.app
```

<Callout type="info">
After using any of these methods, the app will open normally in the future.
</Callout>

### Windows

1. Run the downloaded `.exe` installer
2. Follow the setup wizard
3. Amux Desktop will be added to your Start Menu

{/* IMAGE: Windows installation wizard */}

### Linux

**AppImage:**

```bash
chmod +x amux-desktop-x.x.x.AppImage
./amux-desktop-x.x.x.AppImage
```

**Debian/Ubuntu (.deb):**

```bash
sudo dpkg -i amux-desktop-x.x.x.deb
```

## Data Directory

Amux Desktop stores configuration, database, and logs in the following locations:

| Platform | Path |
| --- | --- |
| macOS | `~/Library/Application Support/amux-desktop/` |
| Windows | `%APPDATA%/amux-desktop/` |
| Linux | `~/.config/amux-desktop/` |

This directory contains:

| File/Folder | Description |
| --- | --- |
| `database.sqlite` | Local database (providers, proxies, logs, tokens, etc.) |
| `logs/` | Application log files |
| `presets/` | Cached provider presets |

## Build from Source

If you prefer to build from source:

```bash
git clone https://github.com/isboyjc/amux.git
cd amux

# Install dependencies
pnpm install

# Run in development mode
cd apps/desktop
pnpm dev

# Build distributable package
pnpm package
```

Platform-specific builds:

```bash
pnpm package:mac      # macOS (.dmg)
pnpm package:win      # Windows (.exe)
pnpm package:linux    # Linux (.AppImage, .deb)
```
